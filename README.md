# Sistema de Gestão de Biblioteca em C

Projeto desenvolvido para a disciplina de Estrutura de Dados (ADS - FATEC Ribeirão Preto), utilizando Lista Encadeada, Fila, Pilha Dinâmica, Árvore Binária de Busca (BST) e Grafo com Matriz de Adjacência.

## Funcionalidades

- Cadastro, busca e remoção de livros (BST)
- Listagem ordenada por ID e por título (Insertion Sort)
- Gerenciamento de conexões entre livros e busca em largura (Grafo + BFS + Fila/Lista)
- Histórico das últimas operações realizadas (Pilha)

## Como compilar e executar

Na raiz do projeto, compile utilizando o `Makefile`:

```bash
make
